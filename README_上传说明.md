## 上传方法
1. GitHub 仓库先保留已有版本备份（可使用提交历史恢复）。
2. 解压 ZIP，上传文件到 **仓库根目录**，保持 zh/、en/、it/ 目录。
3. 若旧文件已存在，用 GitHub 网页编辑替换对应内容；不要把 ZIP 当单个文件上传。
4. 提交到 main；Vercel Deployments 显示 Ready 后检查网页顶部链接及中文驾照页面。
5. 淘宝与闲鱼是 App 分享短链接，部分浏览器会提示打开 App；需要人工测试跳转。

注意：本站表单目前以打开邮件客户端方式咨询，不是在线自动提交。
